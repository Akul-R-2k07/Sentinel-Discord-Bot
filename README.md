## ✨ Features

- **Multi-Functional Commands:** Easily manageable commands located right inside the command files.
- **Custom Welcome & Goodbye Messages:** Send customized join and leave notifications with personalized images.
- **Easy Deployment:** Simple setup that can be hosted locally or uploaded directly to any hosting provider.
